# Comics Meta Organizer — Brief

**What it does.** A local background service for Sergei's YACReader comic library. It scans the library folder by folder, identifies each comic from what the comic itself says (a saved cover reading that agrees with the filename) or from external sources (ComicVine, Metron, GCD, Google Books, publisher/web research, an optional Open Library dump, Google Lens cover search with an optional SerpApi fallback), and writes verified `ComicInfo.xml` into CBZ archives. A backup is removed only after the written file reads back correctly and passes a SHA-256 check. **What Sergei does with it:** keeps it running, watches the dashboard, presses **Pause & release GPU** when he needs the computer, completes Google Lens human verification when the dashboard asks (Yandex is no longer searched since 2026-10-12), then runs YACReader's **Rescan library for XML info**. **What it does not do:** edit YACReader's database; solve CAPTCHAs or spoof browser fingerprints; write metadata from a search match alone, or from a cover reading that disagrees with the filename; take creators from a cover or a year from a copyright line; overwrite a value Sergei or another program wrote; overwrite a conflicting CBZ; start itself after a reboot; correct every existing populated field (unfinished).

## How to start and stop

1. Double-click `run.cmd`. The dashboard is at http://127.0.0.1:8765. The launcher window can be closed.
2. After a reboot, double-click `run.cmd` again. There is no sign-in or startup trigger.
3. To stop: press **Pause**, wait for **Paused**, then end `ComicsMeta-Local-8765` in Windows Task Scheduler.

## Commands

- Dev run: `python app.py`
- Tests: `python -B -m unittest discover -s tests -v` (`-B` writes no `__pycache__`; test folders are removed, so the checkout is left as found)
- In-book credits and publisher-agreement pilot (read-only, run while paused, uses the GPU): `python -B pilot_credits.py --out <folder> [--limit 150]`
- Build: none (no installer or build step)
- Release: Sully bumps `VERSION` and `CHANGELOG.md`, commits, creates a named tag and pushes it. No `package.json` or lockfile.
